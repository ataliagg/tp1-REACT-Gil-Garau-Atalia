## Descripción
Portfolio personal desarrollado para el Trabajo Práctico 1. Incluye una presentación, información sobre mí, habilidades, proyectos reales desarrollados y datos de contacto.

## Instalación
Para ejecutar el proyecto tuve que instalar Node.js y npm. Tambien podemos ayudarnos con otras librerias para la estetica (bootstrap) pero no es necesario, yo las instale pero no las utilice. 

1. Descargar o clonar este repositorio.
2. Abrir una terminal dentro de la carpeta `desarrollo-tp1`.
3. Instalar las dependencias:

   ```bash
   npm install
   ```

## Ejecución local
Desde la misma carpeta, ejecutar:

```bash
npm run dev
```

Abrir en el navegador la dirección que indique la terminal, normalmente `http://localhost:5173`.




# TP2 - Portfolio con React Router DOM

## Descripción del proyecto

Este proyecto es la continuación del Trabajo Práctico 1, en el que desarrollé mi portfolio personal utilizando React y Vite.

En este segundo trabajo incorporé React Router DOM para poder navegar entre distintas páginas sin tener que recargar el sitio.

El portfolio cuenta con un menú lateral que permite acceder a las siguientes secciones:

- **Inicio:** presentación personal.
- **Sobre mí:** información sobre mi perfil y formación.
- **Habilidades:** tecnologías y herramientas que conozco.
- **Proyectos:** algunos de mis trabajos realizados.
- **Contacto:** información para comunicarse conmigo.

## Tecnologías utilizadas

- React
- JavaScript
- JSX
- CSS
- Vite
- React Router DOM
- Git y GitHub

## Funcionalidades

- Navegación entre páginas mediante React Router DOM.
- Menú lateral con las diferentes secciones.
- Uso de componentes y props.
- Listado de proyectos y habilidades utilizando arrays y map().
- Uso de useState y eventos para mostrar u ocultar información.
- Diseño adaptable a diferentes tamaños de pantalla.
